# Workflow atlas design
Build an original public workflow corpus and executable failure simulator, not a dump of any assistant's internal tools or instructions. Public interfaces: JSON-RPC request/response contracts and abstract paginated read and idempotent write operations. Distinguish discovery, validation, execution, observation, and completion. Benchmarks use a deterministic fake service: clean success, pagination, transient read failure, timeout before commit, timeout after commit, absent status capability, and terminal denial. Compare blind retries with inspect-before-retry; measure completion, duplicates, and tool calls. There is no external service execution or claim of LLM-agent benchmark performance.
